Zadanie 6 — Okienka dialogowe i zmienne

1. Rodzaje okienek dialogowych

alert() — wyświetla informację i przycisk OK. Użytkownik potwierdza przeczytanie komunikatu.

prompt() — wyświetla okno, w którym użytkownik może wpisać wartość; zwraca wpisany tekst albo null po anulowaniu.

confirm() — prosi o potwierdzenie; zwraca true po wybraniu OK albo false po wybraniu Cancel.

2. Konwersja zmiennych

parseFloat(x) — konwertuje tekst na liczbę, także z częścią dziesiętną. parseInt(x) — konwertuje na liczbę całkowitą. String(x) lub x.toString() — zamienia wartość na tekst. Wartości pobrane przez prompt() są tekstem, dlatego przed obliczeniami trzeba je skonwertować.

3. Trzy zasady nadawania nazw zmiennym

  1. Nazwa zaczyna się od litery, znaku _ lub $; może zawierać litery bez polskich znaków, cyfry, _ i $.
  2. Wielkość liter ma znaczenie: Rekord i rekord to różne nazwy.
  3. Nie używa się słów kluczowych JavaScript jako nazw zmiennych.

4. Podstawowe typy zmiennych w JavaScript

  • Number — liczby całkowite i zmiennoprzecinkowe.
  • String — tekst.
  • Boolean — wartość logiczna: true albo false.
  • Null — celowo brak wartości.
  • Undefined — wartość niezdefiniowana.
  • Object — obiekt.
